What you cannot do when you draw: the word is never written

Ahmed Moaz · 10 November 2026

The one rule every drawer has to learn in Draw and Guess is that you cannot write the word. You draw it. That sounds obvious, and it is the first thing a new player tries.

What is allowed

You can draw any shape or picture, and you can draw clues around the word, such as a scene.

What is not

Letters that spell the word. Writing is how a drawing game would be easy, so it is banned. If you write it, you break the point of the game for everyone.

Why the rule suits the scoring

A fast guess is worth more than a slow one, up to 500 points at the start and 100 at the end. The drawer is paid according to how quickly the others guess. If you could write the word, everyone would guess at once, and the scoring would be pointless.

So the rule protects the whole score system.

Tricks that stay inside the rule

  1. Draw what the word looks like. A shape the guessers recognise.
  2. Draw what it does. Action is often easier than appearance.
  3. Draw where it lives. A scene gives the category.
  4. Draw what it is next to. A tree for a bird, a table for a cup.

If a word is hard

You choose from several secret words, between two and five. If one is too hard, take another. Speed matters more than ambition.

Hints help

Letters appear one at a time as time runs out, so a drawing that is only a good start can still be guessed.

Try it

You can play Draw and Guess free at Boardit, for two to twelve players. Everyone draws once in each round.

A rule for guessers too

Guessers cannot write the answer for others either, because right guesses are hidden. So the only way to help a friend is to draw better or to guess faster. That keeps the game honest from both sides.

What you can do instead

The rule is about letters, not about drawing. Everything else stays allowed, and the drawing tools are generous: undo takes back the last mark and clear wipes the page, so a drawer who writes by accident can remove the mark and start the shape again.

The rule in short

Pictures only. Letters are for the guessers.
